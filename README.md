# 富足记

一个记在自己手机上的小本子。四类积分，每天写一句：离目标近了、远了，还是原地踏步。

没有账号，没有服务器。记录留在这台设备的浏览器里。

## 四类积分

- 财富积分：事业
- 健康积分：健康
- 人脉积分：人际
- 成长积分：个人

每一笔是 +100、−100 或 0。一天一类可以记很多笔。首页一次看一个方向，左右滑动切换。中间是很大的累计数字，可以为负。设了目标，会有一条能量条，写出已经到了多少，例如 3,200 / 10,000。没设目标就不会假装有一个。低于零时，数字照实显示，能量条不会画成正向进度。

财富积分跨过 10,000、100,000、1,000,000、10,000,000 时，会安静地记一笔称呼：万元户、积蓄十万、百万富翁、千万富翁。

日期和「今天」按北京时间（Asia/Shanghai）计算，不看手机设在哪个时区。

## 本地运行

需要 Node.js 20 或更新版本。

```bash
npm install
npm run dev
```

浏览器打开 [http://127.0.0.1:47231/fuzu-ji/](http://127.0.0.1:47231/fuzu-ji/)。

生产构建：

```bash
npm run build
npm run preview
```

`npm test` 会跑记分、日期和备份的检查。

## 添加到 iPhone 主屏幕

1. 用 Safari 打开 [https://sxzjl.github.io/fuzu-ji/](https://sxzjl.github.io/fuzu-ji/)。微信或其他 App 里的浏览器通常不能安装。
2. 点底部分享按钮。
3. 选「添加到主屏幕」。
4. 名称会显示为「富足记」。

装好之后，它像一个独立的小应用。第一次打开需要联网，以便把页面存进手机。之后没有网络也能打开。

请用构建后的地址或正式网站来安装。开发服务器上的页面每次刷新都会变，不适合装到主屏幕。

## 数据留在这台设备

删除浏览器网站数据、换浏览器，或换手机，记录不会跟着走。换手机前，请先导出。

## 导出和导入

打开「设置」。

- 导出备份：下载一个 JSON 文件，例如 `富足记-备份-2026-11-26.json`。
- 导入备份：选这个文件。导入会替换这台设备上现有的记录和目标。

请把备份文件自己收好。它里面是你写下的句子。
